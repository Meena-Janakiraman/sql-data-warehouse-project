**Data Warehouse and Analytics Project
**
Welcome to my Data Warehouse and Analytics Project repository! This portfolio project covers the full journey from raw source files to business insights: building a SQL data warehouse, cleaning and integrating the data, and analyzing it to support decision-making.

**Project Overview**

**This project has two parts:**

**Data Warehouse (data engineering):** consolidate sales data from two source systems into one clean, analysis-ready warehouse.
**Analytics (data analysis):** use SQL and Power BI to turn the warehouse data into reports and insights.

**Building the Data Warehouse**
**Objective**
Build a data warehouse in [MySQL / SQL Server] that consolidates sales data from multiple sources, so the business can run reliable analytical reports and make informed decisions.

**Specifications**
**Data sources:** two source systems, [ERP] and [CRM], provided as CSV files.
**Data quality:** find and fix data quality issues (duplicates, nulls, inconsistent formats, invalid values) before analysis.
**Integration:** combine both sources into one user-friendly data model designed for analytical queries.
**Scope:** the latest dataset only, with no historization of old versions.
**Documentation:** the data model and cleaning rules are documented so business and analytics teams can understand them.

**Analytics and Reporting**
**Objective**

Use SQL and Power BI to answer business questions from the Gold layer.

Business questions
How have sales changed over time?
Which products and categories perform best and worst?
What does customer behavior look like (top customers, repeat purchases, segments)?
